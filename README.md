# RosaLive Flutuante
Aplicativo Android para reproduzir manualmente dois MP3 em botões flutuantes sobre o TikTok.

- 1 a 99 moedas e 100+ moedas
- Importação de MP3 pelo seletor de arquivos Android
- Controle de volume do áudio, parar, recolher, arrastar e fechar
- Não detecta presentes automaticamente
- Não garante captura do áudio interno pelo TikTok

## Gerar APK
Envie os arquivos para um repositório GitHub e execute o workflow **Compilar APK** em Actions. O artefato RosaLive-APK conterá o APK de depuração.
